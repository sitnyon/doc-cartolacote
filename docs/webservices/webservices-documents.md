# Documents

Le webservice Documents permet de renvoyer un carrousel d'images ou de fichiers.

## URL

``https://map.cartolacote.ch/docs/{type_document}/{identifiant}``

## Paramètre


| Paramètre | Description | Valeurs supportées |
|---|---|---|
| `type_document` **(requis)** | Le type de document que doit renvoyer le webservice | `image` ou `file` |
| `identifiant` **(requis)** | L'identifiant du ou des documents | Ex. : `ASS253REGARD_R53` |
